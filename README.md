## 使用步骤

Abaqus/CAE 2022/2023 周期性边界条件插件，兼容 Python 2.7。
插件文件放在 `ABAQUS\plugins\PeriodicBC`，重新启动 CAE 后选择 **Plug-ins → PeriodicBC**。

1. 先保存原模型，建议复制一个用于周期性计算的模型。材料、实体截面和匹配网格须已建立。
2. 输入模型名和实例名；多个实例用英文逗号分隔。选择 `3D` 或 `QUASI2D`；`QUASI2D`选择厚度轴。
3. 选择试验和材料来源：`TENSION` 拉伸、`COMPRESSION` 压缩、`CREEP` 蠕变、`SHEAR` 简单剪切、`CUSTOM` 自定义；材料来源为 `UMAT`、`CREEP`（内置）或 `ELASTIC`（普通材料）。压缩必须输入负数。
4. 选择 X/Y/Z 或 XY/XZ/YZ，填写 A/B 两个独立目标。预设控制 `MIXED` 表示 A 轴应力控制、B 轴变形控制。蠕变预设固定为应力控制。点击 **Apply preset** 建立路径。
5. 在 Components / Stages 中逐分量选择 `H` 或 `P`。
6. 选择 **Check / Preview**，在 Checks / Report 查看尺寸、配对误差、方程数、步骤和时间路径，再选择 **Generate**。
7. 检查模型中的参考点、方程、BC、集中力及分析步。

## 参数的含义

`H = F-I`。例如 `H11=0.01` 是 X 方向伸长 1%，`H11=-0.01` 是缩短 1%，不是对数应变。简单剪切 `H12=0.01` 是 `u1=0.01*Y`，不是对称张量应变 E12。

`P` 为第一类 Piola 名义应力，按初始单元面积计算。

RP 跨距位移 `d_iJ=H_iJ*L_J`，RP 力 `Q_iJ=P_iJ*V0/L_J`。大变形恒定 P 不等同恒定 Cauchy 真应力。

三维开放 11、22、33、12、13、23 六个分量，宏观 F 的下三角为零，固定宏观取向。零 P 表示该宏观分量不受力，零 H 表示该宏观变形固定。未进入任何方程的 RP 自由度不激活；不对非活动自由度重复施加 BC。

准二维 以 Z 为厚度轴：所有厚度层共享 u1(X,Y)、u2(X,Y)，u3=H33*(Z-Zmin)，不允许厚度剪切或弯曲。第三方向可指定 H33 或 P33。

## 支持单步和多步

- `MULTI`：每行对应一个分析步。HOLD 自动继承上一行；UNLOAD 使用填写的总目标。
- `SINGLE`：将多行合成一个分析步，通过分段幅值实现同一时间，使用第一行名称。全步采用各阶段最小 maxInc，自动提高 maxNumInc。长时间蠕变建议 MULTI，避免保载的小增量。
- `CREATE`：从 Initial 开始新建带本配置前缀的步骤，要求没有用户分析步，避免误接已有预加载状态。
- `EXISTING`：阶段名称、时长须匹配从 Initial 后开始的连续已有步骤；SINGLE 对应一个总时长步骤。不会修改已有时间及 NLGEOM。
- 默认生成线性分段幅值，保持时目标不重置。各分量可通过多行不同目标实现顺序双轴加载。
- 仅支持 MULTI、从零开始的过渡，且必须为 STEP 时间的 TabularAmplitude，从 `(0,0)` 到 `(该阶段时长,1)`。

UMAT 模式采用 Static, General，至少一个材料必须是用户材料；实际时间由 UMAT 控制。内置 Creep 模式采用 Visco，至少一个材料须已有内置 Creep 参数。NLGEOM 默认开启，CETOL 默认 1e-5。所有长度、力、时间须采用一致单位制，与 UMAT 保持一致。

## 模型限制

支持长方体、C3D8/C3D8R、匹配节点和匹配厚度。 注意：边界无对应节点、重合实例节点、过大容差、断开的网格连通 会停止插件生成。多实例物理界面应事先合并连接，插件不自动添加 Tie。

插件拒绝模型中所有非本插件创建的 BC、载荷、约束及相互作用，即使位于其他区域也不行。建议在模型中清理旧载荷后使用。插件不会替用户删除。不支持手工编辑的相关关键字。

使用 `PBC_<tag>_` 前缀，并在 CAE 的 customData 中保存精确创建清单。生成前暂存模型副本。

## 报告和后处理

报告包含控制方式、初始尺寸、面积换算、有效路径、累计时间、保持起始时间和对象清单。
结果报告默认保存到工作目录，可指定已有目录。

RP 历史输出包含 U、RF；应力控制分量额外包含 CF。
位移控制分量从 RF 恢复宏观名义应力，应力控制分量从施加力恢复；不要把自由 RP 的零 RF 误认为零应力。
